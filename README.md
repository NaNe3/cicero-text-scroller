# Overview

In order to demonstrate the Java language, I wrote a text scroller application that allows users to read Cicero's work and navigate through it using keyboard inputs.

The purpose of writing this software was to practice handling user input, file I/O, and terminal manipulation in Java. The creation of this text "scroller" allowed me to explore all of these complicated topics!

# Development Environment

I used the Java Development Kit (JDK) to compile and run the Java code. In addition, VSCode was used in the process of code editing and file management!


The programming language used for this project is Java. No external libraries were used; the project relies solely on the standard Java libraries for file I/O, terminal manipulation, and user input handling.
